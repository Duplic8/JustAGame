## How It Works


[On the platforming level I wanted to make the player feel responsive. So I made the character turn around when moving left as well as adding a method to account for jump buffering. So even if the player presses jump right as the character is about to land, the character will still jump as soon as it lands. When I was looking at a few sample warioware games, I realized that these small changes made the controls feel extremely responsive.]
